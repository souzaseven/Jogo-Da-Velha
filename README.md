## 📋 Descrição
Jogo da velha interativo para dois jogadores com:
- Interface limpa e intuitiva  
- Detecção automática de vitória/empate
- Animações fluidas
- Design totalmente responsivo

## 🎯 Funcionalidades
| Feature | Descrição |
|---------|-----------|
| **Alternância de turnos** | Alterna automaticamente entre X e O |
| **Verificação de vitória** | Checa 8 combinações possíveis |
| **Empate** | Detecta quando não há mais jogadas |
| **Reinício** | Botão para recomeçar o jogo |
